## 已新增的保护

- `MAX_MODEL_REQUESTS=16`：每个研究模型实例最多发起 16 次调用，包括格式修正；超过则下一次请求不会发出。
- `MAX_MODEL_TOKENS=60000`：每次调用前检查已经返回的累计 usage，达到阈值后停止。当前请求仍可能越过阈值，缺失 usage 也无法计数，所以这不是严格 Token 或人民币硬预算。
- 普通 `eval/run.py` 默认 `--max-runs 3`；题目数乘方法数超限，在加载服务与模型调用前拒绝启动。完整评测必须明确 `--max-runs 90`。
- 达到单任务限额时 worker 保存失败状态、安全诊断与已读证据，不伪造已完成答案。401/402 停止普通评测后续条目。

限制作用于单模型实例或单次普通评测计划，不是全账号、全部进程或日累计预算；P0 专用五题脚本与 P2 回放需阅读各自说明。目前已部署并核对 worker 中的配置为 16 次/60000 已观测 Token；上限拦截由模型替身测试验证，没有付费构造超限来测试。真实回归只做固定案例和单题，没有重跑整套三方案。

重新生成离线统计：`python -m eval.audit_usage`。该脚本不会访问网络、读取 Key 或调用模型。
