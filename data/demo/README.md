这是卷章级的小规模语料，不是完整史书。卷217主要为天宝十五载相关内容；不要把本示例当作已包含起兵前所有背景材料。没有扫描件和现代点校本的逐页校勘，字形、纪年及人名可能有转录错误或异文，版本字段明确保留这一限制。古籍原文本身为公有领域，数字转录来源和贡献者权利依站点条款保留；不包含现代译文、付费点校或现代注释。

另有 `web_pages.json`：维基百科《安史之乱》《史思明》各前六个正文段落，共 1,884 字符，是现代通俗文章导入样本，**不是学术研究资料**。`web_provenance.json` 保留页面修订号、贡献者历史入口、CC BY-SA 4.0 许可和抽取规则。这两份摘录遵循 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)；修改后分享这些文本仍需署名并相同方式共享。来源 URL 带 oldid，页面历史提供贡献者列表。

现代百科会引用古籍；两唐书和《通鉴》也可能共享更早史源。不能将这八份数字文本简单当作八位独立见证人。第一版未采集有许可的现代学术论文，研究性解释应等待用户导入来源清楚的研究材料。

## P1 按需补充卷章

`supplement.json` 是 2026-10-20 通过同一个受限运行时 HTTP 客户端和维基文库官方 REST API 取得的两卷，共 23,913 字符：

| 文献 | 卷章 | 固定修订 |
|---|---|---|
| 资治通鉴 | 卷218 | 1996147 |
| 资治通鉴 | 卷222 | 982271 |

`supplement_provenance.json` 保存接口地址、固定页面、提取规则、原文哈希及许可说明。这两卷与基础文本的抽取规则不同：HTML 转文本保留部分页内卷章导航和许可说明，未作繁简转换或影印校勘，不属于现代点校本。古籍原作为公有领域；数字转录按来源 API 返回的 CC BY-SA 4.0 保留署名、页面历史及相同方式共享说明。

两卷在 P1 的 30 题三方案基线结束后才导入；该批次仍固定原有八份资料。要重现实验，不要先导入这两卷。日常使用可在网页上传 `supplement.json` 自动索引，或显式运行 `shijian import data/demo/supplement.json`。库中增加卷章不会自动增加来源独立性，也不证明已穷尽材料。

重新采集（会实际访问固定 Wikimedia 域名并更新快照；更换快照后重跑锚点校验）：

```sh
uv run python scripts/collect_demo.py
uv run python scripts/collect_external_demo.py
uv run python scripts/build_questions.py
```

采集脚本属于维护者对固定公开站点的取材命令，HTTP 工具对任意用户 URL 的处理使用独立的 `shijian.web` 受限抓取实现。不要拿维护脚本代替公开抓取接口。
